## Usage

Calculate maths, units, currencies, dates and time zones in plain English. Start typing with a number or `$` `€` `£` `(` `.` `-` and the answer appears, no keyword needed.

![Calculating $20 + 15% in gbp](images/about/inline.png)

* <kbd>↩</kbd> Copy the result.
* <kbd>⌘</kbd><kbd>↩</kbd> Copy the unformatted value.
* <kbd>⌥</kbd><kbd>↩</kbd> Paste the result into the frontmost app.
* <kbd>⌃</kbd><kbd>↩</kbd> Show more actions.
* <kbd>⇧</kbd><kbd>↩</kbd> Put the result back in Alfred to keep calculating.
* <kbd>⌘</kbd><kbd>L</kbd> Show the result in Large Type.

Calculate things that start with a word, like dates and time zones, via the `=` keyword. The subtitle explains the answer: where an exchange rate came from, the weekday and GMT offset for a time, or how many days away a date is.

![Converting 5pm London time to San Francisco](images/about/time.png)

Search past calculations, or type a new one, via the `history` keyword. Results you copy or paste are saved.

![Calculator history](images/about/history.png)

<kbd>⌃</kbd><kbd>↩</kbd> on any result shows more actions: copy the question or the question and answer, paste, put the question back in the search bar, or remove it from history.

![More actions for a calculation](images/about/history_actions.png)

Work through multi-line calculations via the `calc` keyword. Name a value and reuse it on later lines; every line gets a result and the total adds up as you type.

![Scratchpad with named values and a running total](images/about/scratchpad.png)

* <kbd>⌘</kbd><kbd>K</kbd> Copy the total, the results, or every line with its result, or clear the scratchpad.
* <kbd>⌘</kbd><kbd>↩</kbd> Copy the total and close.

Lines can be plain labels, and currencies convert on the way into the total.

![Scratchpad trip budget](images/about/scratchpad2.png)

Alternatively, calculate selected text or add it to the scratchpad via the Universal Action.

![Universal Actions on selected text](images/about/universal_actions.png)

Currency rates come from the European Central Bank and refresh in the background. Crypto and currencies the ECB doesn't publish use built-in rates, and the subtitle says so.

To avoid duplicate results, turn off Alfred's own calculator in Alfred Preferences → Features → Calculator: uncheck *Enable standard calculator* and *Enable advanced calculator with keyword '='*.

Keywords, decimal places, history and more are in the Workflow’s Configuration.
